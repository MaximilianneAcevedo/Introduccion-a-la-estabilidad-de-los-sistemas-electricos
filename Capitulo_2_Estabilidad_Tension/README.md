# Capítulo 2 — Estabilidad de tensión

Esta carpeta contiene recursos computacionales complementarios asociados con el Capítulo 2 del libro *Introducción a la estabilidad de los sistemas eléctricos*.

## Contenido

- `estabilidad_tensión.py`: script orientado al análisis de estabilidad de tensión y a la construcción de curvas asociadas con el comportamiento de la magnitud de tensión frente a cambios en la potencia demandada.

## Conceptos abordados

- Curvas PV.
- Relación entre magnitud de tensión y potencia activa demandada.
- Efecto del factor de potencia.
- Límites estáticos de transmisión.
- Punto crítico de operación.
- Trayectorias estables e inestables.

## Ejecución

Desde esta carpeta, ejecutar:

```bash
python estabilidad_tensión.py
