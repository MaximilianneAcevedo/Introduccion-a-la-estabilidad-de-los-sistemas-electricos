# Capítulo 3 — Estabilidad transitoria

Esta carpeta contiene recursos computacionales complementarios asociados con el Capítulo 3 del libro *Introducción a la estabilidad de los sistemas eléctricos*.

## Contenido

- `estabilidad_transitoria_primera_oscilacion.py`: script orientado al análisis del modelo clásico del generador y de la respuesta del sistema durante la primera oscilación posterior a una perturbación.
- `tiempo_angulo_critico.py`: script orientado al cálculo del ángulo crítico y del tiempo crítico de despeje de falla.

## Conceptos abordados

- Modelo clásico del generador sincrónico.
- Ecuación de oscilación.
- Curva potencia eléctrica vs. ángulo del rotor.
- Condiciones de prefalla, falla y posfalla.
- Criterio de áreas iguales.
- Ángulo crítico de despeje.
- Tiempo crítico de despeje.
- Pérdida de sincronismo en primera oscilación.

## Ejecución

Desde esta carpeta, ejecutar:

```bash
python estabilidad_transitoria_primera_oscilacion.py
python tiempo_angulo_critico.py
