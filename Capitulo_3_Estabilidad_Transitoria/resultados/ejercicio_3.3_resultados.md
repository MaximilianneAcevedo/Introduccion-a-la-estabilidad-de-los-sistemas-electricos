# Ejercicio 3.3 — Ángulo crítico y tiempo crítico

## Sistema del Ejercicio 3.1

Condiciones de entrada:  
Potencia mecánica Pm = 0.800000 p.u.  
Potencia máxima durante la falla Pef_max = 1.200000 p.u.  
Potencia máxima en prefalla Pepre_max = 2.000000 p.u.  
Potencia máxima en posfalla Pepos_max = 1.850000 p.u.  

Resultados obtenidos:  
Ángulo crítico θcr = complejo  
Tiempo crítico tcr = no aplica  

Interpretación:  
Para el sistema asociado con el Ejercicio 3.1, el cálculo del ángulo crítico entrega un valor complejo, por lo cual no se obtiene un ángulo crítico real válido bajo las condiciones evaluadas.

Este resultado indica que el sistema no perdería estabilidad transitoria en la primera oscilación para la falla planteada. Por tanto, no se define un tiempo crítico de despeje real asociado a pérdida de sincronismo en primera oscilación.

En términos prácticos, bajo estas condiciones, la energía desacelerante disponible después del despeje de la falla es suficiente para compensar la energía acelerante acumulada durante la perturbación.

## Sistema del Ejercicio 3.2

Condiciones de entrada:  
Potencia mecánica Pm = 1.100000 p.u.  
Potencia máxima durante la falla Pef_max = 0.390000 p.u.  
Potencia máxima en prefalla Pepre_max = 1.760000 p.u.  
Potencia máxima en posfalla Pepos_max = 1.510000 p.u.  

Resultados obtenidos:  
Ángulo inicial θ0 = 0.671000 rad  
Ángulo crítico θcr = 1.128800 rad  
Ángulo crítico θcr = 64.680000°  
Tiempo crítico tcr = 0.169700 s  

Interpretación:  
Para el sistema asociado con el Ejercicio 3.2, el ángulo crítico obtenido es θcr = 1.128800 rad, equivalente a 64.680000°. Este valor representa el máximo ángulo de despeje permitido para que el generador conserve la estabilidad transitoria de primera oscilación bajo las condiciones de falla evaluadas.

El tiempo crítico correspondiente es tcr = 0.169700 s. Esto significa que las protecciones deben despejar la falla antes de este tiempo para evitar que el rotor alcance una condición crítica que pueda conducir a la pérdida de sincronismo.
